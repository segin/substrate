### 6b. Editline Library (`lib/edit`)

> **Files:** `editline.c`, `readline.c`, `history.c`, `terminal.c`,
> `el.h` (internal), `histedit.h` (public API in `lib/edit/` and
> `include/histedit.h`).
>
> **Current state:** Core foundation complete — `el_init`/`el_end`/
> `el_reset`/`el_set`/`el_get`/`el_line`/`el_resize` implemented.
> `el_gets` handles full emacs keybindings: insert, backspace, delete,
> `^A`/`^E`/`^B`/`^F`/`^K`/`^U`/`^W`/`^T`/`^Y`/`^_`/`^D`/`^C`/`^L`,
> arrow keys (CSI/SS3/extended), Home/End, Insert/Delete, PgUp/PgDn,
> meta keys (`M-f`/`M-b`/`M-d`/`M-c`/`M-l`/`M-u`/`M-.`/`M-<`/`M->`/`M-y`),
> `^R`/`^S` incremental search, kill ring (8 entries), undo (256 depth),
> overwrite mode, dirty-region refresh, filename completion.
> History supports `H_ENTER`/`H_FIRST`/`H_LAST`/`H_PREV`/`H_NEXT`/
> `H_SETSIZE` with dedup. Terminal caches cols/rows with ioctl/env/80×24 fallback.
