# mandoc

The OpenBSD-derived [mandoc] toolkit: `man`, `mandoc`, `apropos`,
`whatis`, `soelim`, `demandoc`, plus `libmandoc.a` (used by
`contrib/qman`).

Upstream: <https://mandoc.bsd.lv/>
License: ISC (see `build/mandoc-<ver>/LICENSE` after fetch).
Substrate vendoring: tarball + patch series, no source checked in.

## Build

```
./fetch.sh
./build.sh
```

Produces `dist-mandoc/usr/{bin,lib,include,share/man}` ready for
`build-rootfs.sh` to overlay onto the image.

## Substrate-specific overrides

- `configure.local` is generated by `build.sh` to point CC/AR/RANLIB
  at the cross toolchain and lock CFLAGS to `-march=i486 -mtune=i486`.
- `HAVE_OHASH=0` disables the optional libdb-backed makewhatis
  database; `apropos`/`whatis` fall back to walking MANPATH.

[mandoc]: https://mandoc.bsd.lv/
